# YouTube Music Playlist Importer (.txt → Playlist)

Скрипт для импорта треков из `.txt` файла в плейлист YouTube Music через браузер.
Работает прямо в **DevTools Console** (F12) без API, расширений и установки зависимостей.
Подходит для переноса плейлистов из других сервисов, бэкапов, старых списков музыки и массового добавления треков. Но сначала нужно подготовить .txt файл (о нем ниже)

---

## Возможности

- Импорт треков из `.txt`
- Формат: `Artist - Song`
- Автоматический поиск в YouTube Music
- Добавление в **конкретный плейлист**
- Resume после ошибки или остановки
- Удаление дублей перед импортом
- Проверка качества найденного результата
- JSON-отчёт после завершения
- Работа на русском и английском интерфейсе YouTube Music

---

## Формат файла .txt

Один трек на строку, например:
Daft Punk - Harder Better Faster Stronger
Radiohead - Creep
The Weeknd - Blinding Lights

## Как использовать:
1. Откройте YouTube Music.
2. Создайте или откройте нужный плейлист.
3. Нажмите F12, Вкладка (сверху слева в этом окне) Console.
4. Вставьте этот скрипт.
5. Укажите название плейлиста в 24 строке.
6. Нажмите Enter и выберите .txt файл с музыкой.

## Рекомендации
Для лучшего результата:

- запускайте в отдельном окне браузера
- не взаимодействуйте с вкладкой во время импорта
- сначала протестируйте на 5–10 треках
- используйте формат `Artist - Song`
- при проблемах увеличьте `afterSearch`

Что бы остановить, перезагрузите страницу или напишите в консоль: 
window.stopYtmImport = true
Скрипт автоматически сохраняет прогресс в localStorage.
Лучше выполнять в отдельном окне браузера, во время работы не взаимодействуйте с вкладкой
По завершению, будет скачан файл с отчётом (можно открыть блокнотом), а в консоли выведено резюме.

## Тайминги
На случай медленного интернета\пк, необходимо изменять тайминги работы скрипта. 
Если YouTube Music не успевает загружать результаты, увеличьте тайминги.
Чем медленнее интернет или слабее компьютер — тем больше должны быть задержки.
Установлены стандартные тайминги.
const DELAYS = {
  // Пауза после закрытия popup/диалогов через Escape.
  
  afterClosePopups: 700,

  // Небольшая задержка после клика по кнопке поиска.
  // Даёт UI время открыть поисковую строку.
  afterSearchButtonClick: 100,

  // Пауза после очистки search input.
  // Нужна чтобы React/YouTube успел применить пустое значение,
  afterClearSearchInput: 400,

  // Небольшая пауза перед Enter после вставки текста.
  // Даёт input время синхронизироваться с внутренним состоянием UI.
  beforePressEnter: 100,

  !// Ожидание результатов поиска YouTube Music.
  // Главная задержка: зависит от скорости интернета и устройства.
  // Если результаты не успевают появляться — увеличивать.
  afterSearch: 3000,

  // Небольшая пауза перед кликом.
  // После scrollIntoView даёт странице стабилизироваться,
  // чтобы elementFromPoint попадал в правильный элемент.
  beforeClick: 100,

  // Пауза после любого клика.
  // Даёт YouTube Music обработать событие, открыть меню,
  // сохранить трек или обновить DOM.
  afterClick: 900,

  // Ожидание перед проверкой диалога выбора плейлиста.
  // Save-dialog появляется не мгновенно.
  beforePlaylistDialogCheck: 800,

  // Максимальное время ожидания появления окна выбора плейлиста.
  // Если диалог не появился за это время — считаем, что его нет.
  playlistDialogTimeout: 7000,

  // Интервал повторной проверки появления плейлиста.
  // Чем меньше — быстрее реакция, но больше нагрузка на DOM polling.
  playlistDialogCheckInterval: 700,

  // Пауза после выбора плейлиста.
  // Нужна чтобы YouTube успел подтвердить сохранение трека.
  afterPlaylistClick: 1000,

  // Пауза между обработкой треков.
  // Защищает от гонок интерфейса и случайных мискликов.
  // Можно уменьшить для ускорения, но выше риск ошибок.
  betweenTracks: 1200,

  // Интервал polling в waitFor().
  // Как часто проверять наличие элемента в DOM.
  // Меньше = быстрее реакция, но больше нагрузка.
  waitForInterval: 400
};

## Прочие настройки

START_FROM: 0, - с какой строки начнется поиск
RESUME_FROM_SAVED_PROGRESS: false, // на случай перезагрузки страницы и прочих ошибок, начнет добавление с точки сохранения прогресса
REMOVE_DUPLICATES: true, - если в файле будет несколько одинаковых треков - скрипт удалит их автоматически
DEBUG true - вывод логов в консоль
MIN_RESULT_SCORE - поиск идет по совпадению найденого

Значение	Поведение
0.20	Максимум совпадений
0.35	Рекомендуется
0.50+	Строго
0.70+	Может пропускать нормальные треки


## Ограничения

Скрипт работает через UI YouTube Music, поэтому:

зависит от структуры сайта
может сломаться после обновления YouTube Music
не гарантирует 100% точность поиска

Иногда YouTube Music показывает:

артиста вместо трека
кавер
live-версию
ремастер

Для уменьшения ошибок используется система оценки совпадений.

## Disclaimer

Используйте на свой риск.
Скрипт не использует YouTube API и работает локально, через автоматизацию интерфейса браузера.
